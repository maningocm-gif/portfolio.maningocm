# Chariza Mae — Portfolio

A GitHub Pages wrapper for the original Canva-exported portfolio PDF.

## Deploy
1. Upload `index.html` and `portfolio.pdf` to the root of a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.

The site displays the PDF without recreating or altering its artwork.
