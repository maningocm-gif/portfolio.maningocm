# Chariza Mae B. Maningo — Portfolio Website

This is a faithful web conversion of the supplied portfolio PDF.

## What is preserved
- Original artwork, photographs, typography, colors, layout, and section composition are rendered as the supplied portfolio artwork.
- No visual redesign or reflow has been applied.
- The site is responsive in the sense that the artwork scales with the browser width.

## Working interactions
- Email address in the final section opens the visitor's mail client.
- LinkedIn in the final section opens the LinkedIn profile.
- Section anchors are available through keyboard focus/assistive navigation without adding visible UI to the design.

## GitHub Pages
Upload the contents of this folder to a repository and enable GitHub Pages. The entry point is `index.html`.
